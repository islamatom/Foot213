# Foot 213 - App Football Algérie

App PWA pour clubs de quartier en Algérie.

## 📱 Installation iPhone
1. Ouvre Safari
2. Va sur: https://yourusername.github.io/Foot213
3. Clique "Partager" → "Sur l'écran d'accueil"
4. L'app s'installe! 🎉

## 🎨 Fonctionnalités
- Gestion des équipes
- Classement national
- Matchs et résultats
- Chat d'équipe
